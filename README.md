# recursive-enc-dec-ryptor

Реализовать защиту данных пользовательских папок и файлов, находящихся в папке, а также под-папках путем шифрования. 
Для доступа к данным исходной папке необходимо выполнить дешифрование.

Необходимо разработать консольное приложение, которое позволяет:
1. шифровать/дешифровать отдельные файлы;
2. рекурсивно шифровать/дешифровать директории;
3. для защиты данных используется пароль, из которого формируется ключ, 
   а содержимое файла шифруется алгоритмом AES-256-GCM
